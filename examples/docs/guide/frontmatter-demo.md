# Properties

The `---` block above is this document's frontmatter. It renders as a
Properties panel; click it and the raw YAML comes back, which is the only
honest way to edit something the panel does not fully model.

Its `title` is also what names this page in the tree on the left — the file is
called `frontmatter-demo.md`, but nobody has to know that.
